adaptors -- NestyNet Optimization Adaptors
===========================================

The ``adaptors`` module bridges NestyNet_SR models to NestyNet's
Levenberg-Marquardt optimizer: AST-native composites, VarPro adaptors for
templates and DE residuals, Hamiltonian adaptors, and residual wrappers.
