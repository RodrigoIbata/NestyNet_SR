sr\_gs -- Generalized Symmetries
=================================

The ``sr_gs`` module implements the generalized-symmetry layer: affine and
bounded-quadratic point-symmetry discovery, invariant compilation,
symmetry-based reduction, Noether reduction, and algebra certification.
