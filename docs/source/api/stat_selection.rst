stat\_selection -- Statistical Model Selection
===============================================

The ``stat_selection`` module provides archive-conditional statistical
certification for frozen SR/DE candidate archives: provenance-bearing
archives, common-domain loss audits, and paired simultaneous confidence
Pareto fronts.
