# Feynman Complex-Valued Benchmark - Equations with Complex Fields and Complex Coefficients
#
# Goal
# ----
# Complex-valued equation benchmark using native complex notation (i, conj, |z|^2, etc.),
# listing famous physics equations involving complex fields.
#
# Proposed Equations (~25 problems)
# ---------------------------------
#
# Quantum Mechanics (C000-C008)
#   C000: Free-particle Schrodinger (i*hbar*dpsi/dt = -(hbar^2/2m)*d2psi/dx2)
#   C001: Harmonic oscillator Schrodinger (i*hbar*dpsi/dt = -(hbar^2/2m)*d2psi/dx2 + 1/2*m*omega^2*x^2*psi)
#   C002: Schrodinger with potential V(x) (general 1D)
#   C003: Gross-Pitaevskii / nonlinear Schrodinger (i*dpsi/dt = -d2psi/dx2 + g*|psi|^2*psi)
#   C004: Two-level quantum system (i*d[c1,c2]/dt = H*[c1,c2]) -- complex_system
#   C005: Pauli equation / spin-1/2 (2-component complex spinor)
#   C006: Time-independent Schrodinger eigenvalue (-(hbar^2/2m)*d2psi/dx2 + V*psi = E*psi)
#   C007: Hydrogen radial (complex spherical harmonic factor)
#   C008: Dirac equation 1+1D (i*gamma^mu*d_mu*psi = m*psi, 2-component spinor)
#
# Nonlinear Waves & Optics (C100-C105)
#   C100: Nonlinear Schrodinger / fiber optics (i*du/dz + d2u/dt2 + |u|^2*u = 0)
#   C101: Complex Ginzburg-Landau (du/dt = (1+i*a)*d2u/dx2 + u - (1+i*b)*|u|^2*u)
#   C102: Manakov system (coupled NLS: i*du/dz + d2u/dt2 + (|u|^2+|v|^2)*u = 0, same for v)
#   C103: Soliton / KdV-NLS envelope (i*dA/dt + d2A/dx2 + 2*|A|^2*A = 0)
#   C104: Second harmonic generation (i*dA1/dz = kappa*conj(A1)*A2, i*dA2/dz = kappa*A1^2)
#   C105: Parametric amplification (i*dA/dz = kappa*conj(A)*exp(i*Delta*z))
#
# Classical Oscillators & Circuits (C200-C204)
#   C200: Complex damped oscillator (d2z/dt2 + 2*gamma*dz/dt + omega0^2*z = 0)
#   C201: Driven complex oscillator (d2z/dt2 + 2*gamma*dz/dt + omega0^2*z = F*exp(i*Omega*t))
#   C202: Coupled complex modes (dz1/dt = i*omega1*z1 + kappa*z2, dz2/dt = i*omega2*z2 + kappa*z1)
#   C203: Van der Pol in complex amplitude (dA/dt = (mu-|A|^2)*A + i*omega*A)
#   C204: RLC phasor (i*omega*L*I + R*I + I/(i*omega*C) = V)
#
# Condensed Matter & Field Theory (C300-C305)
#   C300: BCS gap equation (complex order parameter ODE)
#   C301: Landau order parameter (dPhi/dt = -a*Phi - b*|Phi|^2*Phi + kappa*d2Phi/dx2)
#   C302: Josephson junction (dphi/dt = V, dV/dt = -sin(phi) - alpha*V + I_ext) -- naturally complexified
#   C303: Stuart-Landau (dA/dt = (mu+i*omega)*A - (1+i*beta)*|A|^2*A)
#   C304: Complex scalar field (Klein-Gordon: d2phi/dt2 - c^2*d2phi/dx2 + m^2*phi = 0)
#   C305: Coupled Bose-Einstein condensates (i*dpsi1/dt = -d2psi1/dx2 + g1*|psi1|^2*psi1 + kappa*psi2, etc.)
#
# Format
# ------
# Tab-separated fields:
# id	type	order	axes	x_axis	field	equation	description	ref	complex_ops	params	param_ranges
#
# Notes:
# - 'type': complex_ode (single complex field ODE), complex_pde (single complex field PDE),
#            complex_system (coupled complex fields)
# - 'order': highest derivative order (0, 1, or 2)
# - 'axes': coordinate axes (comma-separated)
# - 'x_axis': index of evolution axis (0-based), or -1 for eigenvalue/algebraic
# - 'field': complex field name(s) (comma-separated)
# - 'equation': native complex notation using i, conj(z), |z|^2, Re(z), Im(z)
# - 'ref': Feynman Lectures (Volume.Chapter) or standard reference
# - 'complex_ops': complex-specific operators used (conj, mod2, Re, Im, etc.)
# - 'params': parameter names (comma-separated), '-' if none
# - 'param_ranges': suggested [min,max] pairs, '-' if none
#
# All entries involve genuinely complex-valued fields or intrinsically complex coefficients.
#
# =============================================================================
